# STM NUCLEO-F401RE LEARNING PROGRAMS

## Description
This repository is a collection of code with distinct functions for my STM32 Nucleo-F401RE microcontroller. It serves as a progression list as I uncover more knowledge on embedded systems, through documentation or videos.

I am taking a more independant approach in learning, reducing my usage of AI. However, I have used AI for configurations that would otherwise be annoying to deal with myself. In short, AI is used to help me with tasks not essential for my actual learning focus, increasing efficiency of my workflow and learning experience. To fascilitate self documentation, I have included a .md file for each program to give a general description and my own personal thoughts.
